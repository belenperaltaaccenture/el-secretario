# Process: From a Messy Note to Actions

1. Save the original note in `00_ENTERED` with a date.
2. Identify facts, decisions, tasks, questions, and ideas.
3. Flag doubts or contradictions. Do not fill them in by making things up.
4. Propose updates for the main files.
5. Ask for approval before modifying more than one area.
6. Record the approved tasks inside the corresponding project.
7. Keep the source and mark it as processed. Do not delete it.
